## Full Description (Limit: 4000 characters)

```text
TapBot turns your Android phone or tablet into an on-device automation engine. Run lightweight Telegram bots, community management bots, and task automations directly on your device—without paying for VPS hosting or setting up complex cloud servers.

🚀 KEY FEATURES:

• ON-DEVICE EXECUTION:
Run bots natively on Android ART. Your device handles message polling and automation workflows with minimal battery consumption.

• ONE-CLICK BOT CATALOG:
Discover and install ready-to-run automation bots:
- Exon Robot (Group & Chat Management)
- Ping Pong Automation
- Developer Echo & Utility Bots
- Custom MTProto & Bot API Packages

• ZERO-KNOWLEDGE SECURITY:
Your bot tokens and API credentials never leave your hardware. Everything is encrypted using the Android Keystore system with AES-256 hardware keys.

• RELIABLE FOREGROUND ENGINE:
Equipped with a low-overhead foreground service that keeps your automations online even when the screen is locked, featuring instant Start/Stop controls and battery-conscious polling backoffs.

• LIVE STREAMING CONSOLE:
Inspect real-time logs, request traffic, incoming commands, and bot status right from the Material 3 execution console.

• OPEN & TRANSPARENT:
Built with Kotlin and Jetpack Compose. Transparent, secure, and developer-friendly.

---

PERMISSIONS EXPLAINED:
- Network / Internet: To connect to official Telegram endpoints and fetch bot packages.
- Foreground Service: To keep bot automations active in the background with an ongoing status notification.
- Notifications: To display runner controls (Open / Stop) directly from your lock screen.

Turn your unused Android device into a 24/7 automation server with TapBot!
```
