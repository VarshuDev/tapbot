On-Device Architecture

Three minutes from drawer to server.

No Linux rooting. No Termux workarounds. Just a compiled Android service running directly on native ART.

Install Standalone APK

Sideload a clean, single 19.3 MB binary. Compatible with Android 8.0 up to Android 15+. Requires zero Google Play Services or root permissions.

adb install tapbot-v2.2.0.apk

STEP 2 · ENCRYPTION

Android Keystore Enrollment

Create a bot via @BotFather on Telegram. Paste your bot token into TapBot. The token is encrypted inside the hardware security enclave with AES-256-GCM.

Keystore.encrypt(token, AES_GCM)

SECURITY ENCLAVE

Hardware Keystore Encryption

Telegram bot tokens are sealed within Android's hardware security module (KeyStore) using AES-256-GCM. Plaintext tokens never hit flash memory.

• AES-256-GCM authenticated cipher
• Android KeyStore secure enclave
ZERO WEAR ENGINE

0 Bytes Flash Wear

Traditional servers constantly write log files that degrade phone eMMC/UFS memory. TapBot runs log rings strictly in RAM buffers, writing 0 bytes to storage per hour.

• Circular in-memory RAM log buffers
• Prolongs device lifespan for years
NATIVE ART RUNTIME

Direct Bytecode JIT Execution

No bloated Node.js runtimes or slow Python interpreters. Compiled Kotlin runs directly on Android ART with Coroutines Flow, consuming only 14.2 MB of heap memory.

• AOT / JIT optimized bytecode
• 14.2 MB Heap / ~0.17% system RAM
DOZE RESISTANT

24/7 Doze Immunity

Foreground service lifecycle with sticky restarts and battery optimization exemption. TapBot stays alive through aggressive OEM task managers and network transitions.

• PARTIAL_WAKE_LOCK protection
• Auto-reconnect on Wi-Fi/4G drops
