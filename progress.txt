# TapBot - Ralph Execution Progress

## Codebase Patterns
- Multi-module Android architecture: `:app`, `:feature:catalog`, `:feature:botdetail`, `:core:runner`, `:core:model`, `:core:network`, `:core:security`, `:core:logging`.
- Bot runtimes extend `BotRuntime` with `start()`, `stop()`, and `isRunning()` coroutine lifecycles.
- Keystore credentials stored via Android Keystore AES-256-GCM in `EncryptedSharedPreferences`.
- Telegram Long-Polling implemented in `core:runner` with backoff logic and cancelable coroutine jobs.
- UI built with Jetpack Compose following OLED Dark Mode design system (`BotHubTheme`).

## 2026-10-28 - US-004: Autonomous Background Watchdog Coroutine
- Created `DeviceWatchdog` in `com.tapbot.core.runner.watchdog`.
- Detects low battery when battery <= threshold (default 15%) and discharging.
- Enforces 30-minute debouncing between battery warnings (`lastLowBatteryAlertTime == 0L || currentTimeMillis - lastLowBatteryAlertTime >= debounceMillis`).
- Detects and deduplicates bot fleet crash events via `checkCrashes(instances)`, alerting the configured owner with bot name, ID, crash reason, and recovery actions (`/logs`, `/restartbot`).
- Delegated watchdog execution in `CommanderBotRuntime.kt` to `DeviceWatchdog`.
- Created comprehensive unit tests in `DeviceWatchdogTest.kt`. All 55 tests passed.

## 2026-10-28 - US-005: In-Chat Direct APK Document Delivery (/apk)
- Created `ApkDeliveryService` in `com.tapbot.core.runner.delivery`.
- Resolves host device APK from `context.applicationInfo.sourceDir` with fallbacks to workspace release builds.
- Computes SHA-256 integrity checksum using standard streaming `MessageDigest`.
- Enforces Telegram 50MB Bot API file upload ceiling with fallback instructions.
- Formats rich release caption with version name, version code, size in MB, and SHA-256 hash.
- Unit tested file hashing, size checking, limit triggers, and delivery upload. All unit tests passed.
