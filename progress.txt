# TapBot v2.3.0 - Ralph Multi-Phase Execution Progress

## Codebase Patterns
- Multi-module Android architecture: `:app`, `:feature:catalog`, `:feature:botdetail`, `:core:runner`, `:core:model`, `:core:network`, `:core:security`, `:core:logging`.
- Pure JVM unit tests in `:core:runner` use `unitTests.isReturnDefaultValues = true` (no Robolectric) — always support `context: Context? = null` fallbacks and standard JDK APIs (`DocumentBuilderFactory`, `java.io.File`) for new services.
- Keep existing constructors and `TelegramApiClient` / `BotDetailViewModel` / `CatalogViewModel` / `BotInstanceManager` signatures backward-compatible via defaults or overloads so existing unit tests compile cleanly.
- Bot runtimes extend `BotRuntime` with `initialize()`, `start()`, `stop()`, and `state: StateFlow<BotRuntimeState>`.
- Keystore credentials stored via Android Keystore AES-256-GCM in `KeystoreSecureCredentialStore`.
- UI built with Jetpack Compose following OLED Dark Mode (`BotHubTheme`).
