Three minutes from drawer to server.

No Linux rooting. No Termux workarounds. Just a compiled Android service running directly on native ART.

01
PHASE 01 // DEPLOYMENT

Install Standalone APK

Sideload a single 19.3 MB binary. Compatible with Android 8.0 up to Android 15+. Operates completely decoupled from Google Play Services.

adb install tapbot-v2.2.0.apk
02
PHASE 02 // ENCLAVE

Keystore Token Sealing

Obtain an API token via @BotFather on Telegram. TapBot locks the credential directly in the Android Keystore enclave with AES-256-GCM authenticated cipher.

Keystore.encrypt(token, AES_GCM)
03
PHASE 03 // AUDIO ENGINE

Launch TapStream

Select TapStream Music or TapBot Commander and tap Start. The process connects to Telegram's long-polling gateway via OkHttp WebSockets in under 200ms.

OkHttp.newWebSocket(tg_gateway)
04
PHASE 04 // PERSISTENCE

Immortal Foreground State

TapBot acquires a partial CPU wake lock and background service notification. Plug in the device charger, put the phone in a drawer, and your server runs permanently.

WakeLock.acquire() // Uptime: INF

KEYSTORE ENCLAVE

Hardware Token Encryption

Bot tokens are sealed inside Android's hardware security module (KeyStore) using AES-256-GCM. Unencrypted tokens never touch flash memory.

• Authenticated AES-GCM cipher
• Hardware-backed key isolation
MEMORY INTEGRITY

0 Bytes Flash Storage Wear

Logging engines constantly degrade internal phone eMMC/UFS storage. TapBot stores telemetry strictly in RAM ring buffers, writing 0 bytes to disk.

• In-memory volatile circular ring
• Eliminates eMMC wear completely
ART JIT/AOT

Native ART Execution

No heavy Node.js runtime layers or slow Python interpreters. Compiled Kotlin bytecode executes directly on native Android ART with Coroutines Flow.

• 14.2 MB Heap RAM allocation
• Pure non-blocking Coroutine I/O
PERSISTENCE

Doze Mode Immunity

Foreground service execution backed by sticky process flags and battery optimization exemption. TapBot persists through aggressive OEM task killers.

• PARTIAL_WAKE_LOCK protection
• Automatic network reconnect
